# Playwright QA Automation Portfolio

A small QA Automation project created with Playwright and TypeScript.

The project demonstrates UI testing, end-to-end testing, negative testing and API testing.

## Technologies

- Playwright
- TypeScript
- Node.js
- REST API Testing
- Git / GitHub

## Test Scenarios

### Login Testing

- Login with valid credentials
- Login with invalid credentials
- Validate error message

### End-to-End Checkout

- Login
- Add product to cart
- Open shopping cart
- Complete checkout form
- Finish order
- Validate successful order

### API Testing

- GET users and validate HTTP 200 response
- Validate JSON response properties
- POST a new user and validate HTTP 201 response
- Validate returned user data
- Test invalid endpoint and validate HTTP 404 response
