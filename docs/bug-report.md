# Bug Report

## Bug ID

BUG-001

## Title

Login error message remains visible after entering valid credentials

## Environment

- Application: SauceDemo
- Browser: Chromium
- Operating System: Windows 11
- Test Type: Manual Testing

## Preconditions

- User is on the SauceDemo login page.

## Steps to Reproduce

1. Open the SauceDemo login page.
2. Enter an invalid username and password.
3. Click the **Login** button.
4. Verify that an error message is displayed.
5. Replace the invalid credentials with valid credentials.
6. Click the **Login** button again.

## Expected Result

The user should successfully log in and the previous error message should no longer be visible.

## Actual Result

The previous error message remains visible after valid credentials are entered.

Medium
